# Changelog

## [1.0.0] - 2026-11-25
### Added
- Complete GitHub Pages-compatible digital hub with Home, Projects, Project Detail, GitHub Intelligence, Work, Journal, Article Detail, Knowledge Archive, About, Contact, and local-first Admin Workspace.
- Automated GitHub REST + GraphQL collector (`scripts/sync-github.mjs`) and JSON schema/security validator (`scripts/validate-schemas.mjs`), synced against `AbdoKamelAyed` (19 public repositories, 46 sampled commits, 216 public events).
- Bilingual English (LTR) and Arabic (RTL) interface, Light/Dark/Glass themes, unified instant search modal, and decoupled unit test suite (`src/utils/analytics.test.ts`).
